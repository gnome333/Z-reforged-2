# Правила для Glua / Garry's Mod

## Реалмы (Realm)
- Всегда проверяй, в каком реалме выполняется код (SERVER, CLIENT, SHARED).
- Никогда не вызывай серверные функции на клиенте и наоборот.

## Безопасность сети
- Любые сетевые сообщения (`net.Receive`) должны иметь строгую валидацию на сервере (проверка `IsValid`, дистанции, кулдаунов).
- Никогда не доверяй данным от клиента (позиции, урон, энтити).

## Код
- Используй локальные переменные (`local`), не засоряй глобальную область.
- Избегай создания таблиц и векторов (`Vector()`, `Angle()`) внутри хуков, вызываемых каждый кадр (`Think`, `HUDPaint`).
